# Screenshots

Drop panel screenshots here to show them off in the main README. Suggested set:

| File | Shot |
|---|---|
| `dashboard-dark.png` | Download dashboard, dark theme |
| `dashboard-light.png` | Download dashboard, light theme |
| `setup.png` | First-run setup wizard |
| `proxy.png` | Proxy / subscription page |
| `files.png` | Folder browser |

To capture them: run `python main.py` (or `docker compose up -d`), open
`http://localhost:36091`, and screenshot each view. Then add a **Screenshots**
section to `README.md`, e.g.:

```html
<p align="center">
  <img src="docs/screenshots/dashboard-dark.png" width="45%" />
  <img src="docs/screenshots/dashboard-light.png" width="45%" />
</p>
```
